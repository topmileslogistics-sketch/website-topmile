# public/

Files in this folder are served from the root of the site.
`public/truck-highway.jpg` is reachable at `/truck-highway.jpg`.

Photos added here only appear on the homepage once they are listed in
`sitePhotos` at the bottom of `src/config/site.ts`.

- `logo-emblem.png` — the header logo and the emblem used in the social
  sharing image. Do not delete.
